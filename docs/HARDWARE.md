## Gewünschte Einordnung

Windows, macOS und Linux gehören zum Zielumfang. Windows bleibt die häufigste
Arbeitsumgebung. Der Pi kann später als eigener Linux-Performance-/Sensor-Knoten
untersucht werden; Arduino-Module als mögliche Live-Controller/Instrument-Eingaben.
Das sind Integrationsideen, keine bereits funktionierenden Verbindungen.

Mögliche spätere Reihenfolge: Bestand genau erfassen, einen einzelnen Sensor
lesen, Werte begrenzen/glätten, gezielt einen musikalischen Parameter steuern,
erst danach mehrere Module, MIDI/OSC oder verteilte Performance kombinieren.
Vor Anschluss müssen Boardmodelle, elektrische Daten und Pinbelegung zum
jeweiligen konkreten Modul passen. Es gibt hier noch keine Anschlussanweisung.

## Aktueller Nachweis

Kein Pi angesprochen, kein Arduino geflasht, keine USB-/GPIO-Geräte kontrolliert,
keine Firmware installiert und keine Sensorwerte als gemessen ausgegeben.
Auch macOS-/Linux-Hardwaretests sind noch offen. Direkte Codearbeit und Tracker
bleiben innerhalb dieses Projekts höher priorisiert als aufwendiges Hardware-Setup.
